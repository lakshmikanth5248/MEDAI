# 🗄️ Supabase Database & Frontend Mapping

Because this project uses a **Microservices Architecture**, the database is split into **7 different schemas** to keep data isolated (instead of everything being in the default `public` schema).

> [!IMPORTANT]
> **How to find your tables in Supabase:**
> 1. Go to the **Table Editor** in your Supabase dashboard.
> 2. Look for the dropdown menu at the top left that says `public` (next to the search bar).
> 3. Click it and select one of the schemas below (e.g., `clinic_auth`, `clinical`, `pharmacy`) to see your tables!

Here is the exact mapping of your frontend features to the backend database tables.

---

## 🔐 Auth Service (Schema: `clinic_auth`)
Handles login, registration, and user roles.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| Login / Users | `clinic_auth` | `users` | All login credentials and roles |
| Reception Staff | `clinic_auth` | `staff_profiles` | Additional details for staff members |
| Password Reset | `clinic_auth` | `password_reset_tokens` | Tokens for "Forgot Password" |

---

## 🏥 Clinical Service (Schema: `clinical`)
The core clinical features like doctors, patients, and appointments.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| Departments Page | `clinical` | `departments` | Clinic departments (e.g., Cardiology) |
| Doctors List | `clinical` | `doctors` | Doctor profiles, fees, availability |
| Patients List | `clinical` | `patients` | Patient demographics and vitals |
| Appointments | `clinical` | `appointments` | Booked appointments |
| Consultations | `clinical` | `consultations` | Doctor's consultation notes, symptoms, tests |
| Reception Staff | `clinical` | `receptionists` | Dedicated reception staff profiles |

---

## 💊 Pharmacy Service (Schema: `pharmacy`)
Medical store and medicine inventory management.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| Medical Stores | `pharmacy` | `medical_stores` | Details of the physical store/branch |
| Medicine Inventory | `pharmacy` | `medicine_inventory` | Medicines, stock levels, pricing, expiry |

---

## 📝 Prescription Service (Schema: `prescription`)
Digital prescriptions generated by doctors.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| Prescriptions | `prescription` | `prescriptions` | The top-level prescription record |
| Medicines in Rx | `prescription` | `prescription_items` | The specific medicines prescribed (dosage, qty) |

---

## 💰 Billing Service (Schema: `billing`)
Invoices and payments.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| Billing / Invoices | `billing` | `bills` | Total bill, discount, tax, payment method |
| Bill Details | `billing` | `bill_items` | Individual line items on a bill |

---

## 🔔 Notification Service (Schema: `notification`)
In-app alerts, SMS, and Email logs.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| In-App Alerts (Bell) | `notification` | `notifications` | The actual alert messages |
| Read Status | `notification` | `notification_reads` | Tracks who read which notification |
| SMS Logs | `notification` | `sms_logs` | History of Twilio SMS sent |
| Email Logs | `notification` | `email_logs` | History of Emails sent |

---

## ⚙️ Core Service (Schema: `core`)
System-wide settings and activity logging.

| Frontend Feature | Schema Name | Table Name | Description |
|---|---|---|---|
| Clinics / Branches | `core` | `clinics` | Clinic branch details |
| System Settings | `core` | `clinic_settings` | Global JSON settings |
| Dashboard Activity | `core` | `activity_log` | System audit logs (who did what) |
